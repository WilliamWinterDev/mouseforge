    General

    Closing this window keeps MouseForge running in the tray. Use the tray icon's menu to quit.

    One-time side panel setup

    The Aerox 9's 12 side buttons send the number keys 1–= out of the box. Windows can't tell those apart from your keyboard, so for remapping, the side panel needs to send F13–F24, which no normal keyboard has. This is saved in the mouse itself, so you only do it once.

    Side buttons you don't remap send F13–F24, which most apps ignore. If you uninstall MouseForge, restore the number keys first. Quit SteelSeries GG too: it also writes to the mouse.
